## 项目背景

大疆创新在京东平台积累了超过100万老用户，但运营策略以全量推送为主，缺乏用户分层。本项目针对老用户群体，构建扩展的 RFM-A 模型（增加 Accessories 配件购买维度），实现精细化运营。

## 创新点

- 在传统 RFM 基础上增加 **A（Accessories）维度**，衡量用户购买延伸产品（配件）的倾向
- 结合京东平台特有数据（浏览品类、加购未付、评价内容）
- 运营策略与聚类结果闭环——推送→回收→迭代

## 分析流程

1. **数据抽取**：从京东后台+内部CRM提取老用户全量数据
2. **特征工程**：构建 R、F、M、A 四个维度的评分卡
3. **聚类分析**：K-Means（K=4），轮廓系数验证
4. **画像输出**：为四类人群命名并撰写运营手册
5. **AB测试**：差异化推送 vs 全量推送，对比效果

## 最终效果

| 指标 | 优化前 | 优化后 | 变化 |
|------|--------|--------|------|
| 月度 GMV | 基线 | - | +2.5% |
| 配件销量 | 基线 | - | +1000单/月 |
| 复购率 | 基线 | - | +1.2% |
| 优惠券核销率 | 基线 | - | +12% |
