## 后期调色的正确心态

后期不是"造假"，而是**还原和强化拍摄时的感受**。相机传感器记录的画面往往比人眼看到的更平淡，后期调色就是在弥补这个差距。

## Lightroom 基本工作流

### 第一步：基础修正

1. **裁剪与水平矫正**：先检查画面是否水平，构图是否满意
2. **镜头校正**：启用「镜头校正」移除暗角和畸变
3. **白平衡**：调整色温和色调，还原真实的白色

### 第二步：影调调整

| 参数 | 作用 | 建议 |
|------|------|------|
| 曝光度 | 整体亮度 | 先定基调 |
| 对比度 | 明暗对比强度 | +10~+30 增加立体感 |
| 高光 | 亮部细节 | 减高光保留天空/皮肤细节 |
| 阴影 | 暗部细节 | 提阴影展现暗部内容 |
| 白色 | 最亮区域 | 微调即可 |
| 黑色 | 最暗区域 | 加一点让暗部不死黑 |

### 第三步：颜色调整

- **鲜艳度（Vibrance）**：只增加低饱和度颜色——更自然
- **饱和度（Saturation）**：所有颜色一起增强——慎用
- **HSL面板**：针对特定颜色调整色相、饱和度、明度

### 第四步：细节增强

- **锐化**：让边缘更清晰（默认值通常足够）
- **降噪**：高ISO照片需要适度降噪
- **去朦胧**：去除雾霾感，增加清晰度

## 常见的调色风格

| 风格 | 特点 |
|------|------|
| 日系清新 | 低对比、偏蓝绿、肤色偏橙、曝光偏亮 |
| 胶片复古 | 加颗粒、褪色、暖色调、暗角 |
| 电影感 | 16:9裁切、青橙色调、暗部偏蓝 |
| 黑白 | 去饱和 + 高对比度 + 颗粒 |

## 新手建议

1. **先拍RAW**——JPG是相机帮你调好的，RAW才是你的画布
2. **建立自己的预设**——喜欢的调色风格保存为预设，提高效率
3. **不要过度后期**——HDR拉到满、饱和度拉爆 = 一眼看出是新手
4. **对比原片**——经常按「\」键对比调整前后，避免调偏
