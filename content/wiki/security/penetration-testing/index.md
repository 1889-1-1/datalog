## 什么是渗透测试

渗透测试是**在授权下**模拟攻击者对目标系统进行安全评估的过程。目的是在真正的攻击者发现漏洞之前找到并修复它们。

> ⚠️ **未经授权的渗透测试是违法的！** 本文仅供学习了解。

## 渗透测试流程 (PTES)

### 第一阶段：信息收集（侦察）

尽可能多地收集目标信息，不直接与目标交互。

- **域名信息**：whois查询、DNS记录、子域名枚举
- **IP 范围**：ASN查询、反向IP
- **技术栈**：服务器类型、编程语言、框架版本
- **人员信息**：员工邮箱列表、组织架构
- **工具**：`whois`、`nslookup`、`dig`、`theHarvester`、`Shodan`

### 第二阶段：扫描与枚举

主动探测目标，识别入口点。

- **端口扫描**：`nmap -sV -sC target.com`
- **目录枚举**：`dirb`、`gobuster`、`ffuf`
- **漏洞扫描**：`Nessus`、`OpenVAS`
- **Web扫描**：`Nikto`、`Burp Suite`

### 第三阶段：漏洞利用

利用发现的漏洞获取访问权限。

- **SQL注入**：`sqlmap -u "http://target.com/page.php?id=1"`
- **XSS利用**：`BeEF` 框架
- **密码攻击**：`Hydra`（在线爆破）、`hashcat`（离线破解）
- **Metasploit框架**：`msfconsole`

### 第四阶段：权限提升

从低权限提权到系统最高权限。

- **本地信息收集**：`linpeas.sh` / `winPEAS.exe`
- **内核漏洞利用**：`linux-exploit-suggester`
- **配置错误利用**：SUID二进制、sudo配置、计划任务

### 第五阶段：横向移动

在目标内网中扩散。

- 密码哈希传递 (Pass-the-Hash)
- SSH密钥窃取
- 内网扫描与跳板搭建

### 第六阶段：报告

这是渗透测试最重要的产出：

- 发现的漏洞列表（按危害等级排序）
- 漏洞复现步骤
- 修复建议
- 时间线和攻击路径图

## 核心工具包

### Kali Linux

内置 600+ 安全工具的专用 Linux 发行版。渗透测试的事实标准平台。

### 必会工具

| 工具 | 用途 |
|------|------|
| Burp Suite | Web 应用渗透测试（拦截/修改 HTTP 请求）|
| Nmap | 网络扫描与端口探测 |
| Metasploit | 漏洞利用框架 |
| Wireshark | 网络流量分析 |
| John the Ripper / Hashcat | 密码破解 |
| Gobuster / ffuf | 目录/文件枚举 |
| Sqlmap | SQL 注入自动化利用 |
| Netcat | 网络工具（端口监听/反弹shell）|

## 学习路径

1. ✅ **先学好Web开发基础**——不了解HTTP就不懂Web安全
2. ✅ **OWASP Top 10**——从最常见的漏洞开始
3. ✅ **搭建实验环境**——DVWA、WebGoat、HackTheBox、TryHackMe
4. ✅ **考个认证**——CEH（入门）、OSCP（硬核）
5. ✅ **参与漏洞赏金**——HackerOne、Bugcrowd

## 道德红线

- 🟢 在授权的目标上测试
- 🟢 在隔离的实验环境学习
- 🟢 发现漏洞通知对方
- 🔴 未经授权的渗透
- 🔴 利用漏洞获取利益
- 🔴 破坏/篡改数据

> **永远记住**：渗透测试技能是一把双刃剑。用它来保护系统，而非破坏系统。
